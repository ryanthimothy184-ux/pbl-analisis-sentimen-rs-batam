# pbl-analisis-sentimen-rs-batam
Projek ini menganalisis sentimen ulasan Google Maps terhadap pelayanan rumah sakit di Kota Batam menggunakan pendekatan NLP dan machine learning. Data ulasan melewati tahap preprocessing, lalu diklasifikasikan menjadi sentimen positif, netral, atau negatif. Hasilnya berupa distribusi sentimen pengguna yang bisa jadi bahan evaluasi berbasis data bagi manajemen rumah sakit.
